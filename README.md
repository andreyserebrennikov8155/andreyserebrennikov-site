# Сайт Андрея Серебренникова

Личное портфолио: разработчик + вокалист и автор песен. Обычный статический сайт —
без сборки, без библиотек и без сервера.

## Как открыть

Просто двойным кликом открыть `index.html` в браузере.

Если хочешь смотреть как через локальный сервер — проще всего двойным кликом по
`start_site.cmd` (или по ярлыку «Мой сайт» на рабочем столе): он сам проверит порт,
поднимет сервер и откроет браузер на `http://127.0.0.1:8000`.

То же самое руками:

```
cd E:\ProjectAI\My_site
python -m http.server 8000 --bind 127.0.0.1
```

Затем `http://127.0.0.1:8000`. Остановка — Ctrl+C в окне сервера (или закрыть окно).

Важно: встроенный `python -m http.server` не умеет отдавать файл по частям (Range),
поэтому большие ролики через него могут не проигрываться. Для просмотра видео
лучше открыть `index.html` двойным кликом — с диска всё работает.

## Что где править

- Сменить текст о себе — блок `<section class="section" id="about">`.
- Разделов с вкладками три. «Проекты разработчика»: готовый — «Казначей 1», в разработке — Web_Parser (веб-приложение для текстовых документов в разных форматах, описание временное). «Проекты Музыканта»: готовый — песня «Я нарисую», в разработке — «Запись мини-альбома». «Аудио»: «Мои песни» и «Кавера». Проектные вкладки переключаются кнопками `.project-tab`, аудио — `.audio-tab`; каждая группа независимо.
- Добавить проект — скопировать `<article class="project-card">` в нужную панель: `#projectPanelReady` / `#projectPanelDev` для разработчика, `#musicPanelReady` / `#musicPanelDev` для музыки — и сделать то же в обеих версиях сайта.
- Порядок разделов: после «Проектов Музыканта» сразу идёт «Выступления с концертов» (`#video`), затем «Аудио» (`#songs`), «Фото» и «Контакты»; метки 04–07. Раздел `#music` с вводным текстом, списком пяти песен и блоком «От ноты к файлу» удалён 19.11.2026 как дублирующий информацию — не возвращать. Кнопка «Моя музыка» в первом экране ведёт на `#songs`. Вводного абзаца про «три ролика…» в видео нет. Меняя порядок, меняй метки и пункты меню в обеих версиях сайта.
- Добавить песню — теперь только через аудиозапись в `#songs` (пункт «Добавить аудиозапись» ниже). Авторская — если в подписи указано «Серебренников Андрей», иначе кавер.
- Подпись над фотографиями — «Частичка моей жизни» (было «Мои снимки. Нажми на кадр…»).
- Раздел «Фото» показывает только вертикальные кадры, по два в строке. Фото в одной строке подобраны с одинаковой пропорцией (04 и 09 — 3:4, 06 и 07 — около 2:3), поэтому они одной высоты и между ними нет пустых мест. Горизонтальные снимки убраны по просьбе Андрея.
- Добавить фото — положить исходник в `photo/`, сделать лёгкую копию `assets/photos/photo-NN.jpg` (максимальная сторона 1400 px, JPEG quality 84, пропорции не менять) и дописать такую же строку `<a class="photo-item">` в подходящую пару `.photo-row` раздела `#photos` — в обеих версиях сайта. Подбирай фото с такой же пропорцией, иначе в строке появится зазор. Фото не обрезается, по клику открывается целиком.
- В разделе «Аудио» две вкладки: «Мои песни» (`#audioPanelMine` — «Я нарисую», «Ожидание») и «Кавера» (`#audioPanelCovers` — «Не бойся», «Следом за тобой», «Ты обнимешь меня»). Вводный абзац «Пять треков из моего репертуара…» убран по просьбе Андрея. Начальное состояние плеера (`#audioTitle`, `#audioSub`, `<source>`, активный трек) должно совпадать с открытой по умолчанию вкладкой — сейчас это «Я нарисую».
- Добавить аудиозапись — положить mp3 в `audio/` и скопировать кнопку `<button class="track">` в нужную панель вкладки с новыми `data-src`, `data-title`, `data-sub`, обновив нумерацию `.track-num` в обеих панелях. В подписи обязательно указывать источник файла.
- Блок «Подарок от разработчика» (`.gift-player`) оформлен как карточка с декоративным мини-плеером и кнопками: «Открыть своё видео», «Снять 5 кадров», «Снять 20 кадров с этого места» и «Снять 10 кадров подряд». Не удаляй ID `videoEmpty`, `pickVideoBtn`, `videoFileInput`, `captureFramesBtn`, `captureFromCursorBtn`, `captureStepFramesBtn`, `frameStatus`, `frameResults`, `downloadAllFramesBtn` — на них завязан `script.js`. На телефоне карточка становится в одну колонку, миниатюры кадров идут по две в строке.
- Кнопка «Снять 5 кадров» берёт пять моментов равномерно по всему ролику, а «Снять 20 кадров с этого места» — двадцать кадров подряд с шагом 0,1 с от позиции курсора (окно 1,9 с; если до конца ролика меньше, старт сдвигается назад). Кадры сохраняются в полном разрешении видео — проверено на 4K: 3840×2160; миниатюры в `#frameResults` показывают кадр целиком, клик скачивает JPEG отдельным файлом. Браузер на больших роликах перематывает не идеально точно и иногда показывает один и тот же кадр для двух соседних моментов — поэтому снятый кадр сверяется с предыдущим и при полном совпадении перемотка повторяется чуть дальше (+0,045 с от времени реально показанного кадра), чтобы в серии не было дублей. После съёмки появляется кнопка «Скачать все кадры (ZIP)» — она собирает архив `кадры.zip` прямо в браузере, без сервера и библиотек. Во время съёмки в `#frameStatus` виден прогресс, после смены ролика старые кадры удаляются. Если сайт открыт прямо с диска и кадры не снимаются, выбери ролик кнопкой «Открыть своё видео».
- Кнопка «Снять 10 кадров подряд» снимает десять кадров с шагом ровно в один кадр ролика: так видно каждый кадр файла, без пропусков, и можно сравнить качество соседних кадров. Частота кадров заранее неизвестна, поэтому шаг подбирается сам: начинается с 0,012 с, при повторе кадра растёт в 1,4 раза (до 8 попыток, не больше 0,1 с), при перескоке через кадр уменьшается вдвое, а после удачного кадра уточняется по времени реально показанного кадра. Дубли определяются по этому времени (разница меньше 0,002 с), картинка — запасной вариант, когда время недоступно.
- Под видео внутри рамки плеера показывается строка «Качество видео: 1080 × 1920» (`#videoQuality`) — разрешение текущего ролика. Она обновляется сама при переключении видео и при выборе своего файла. Не удаляй ID `videoQuality`.
- В блоке плеера показывается только название ролика: никаких пояснений и таймкодов в `#videoTitle`. Новую кнопку `.video-choice` добавляй с `data-title` без времени — иначе время появится в заголовке при переключении. В самих кнопках списка длительность пока остаётся в `<small>`.
- Добавить видео — положить mp4 в `video/`, сделать постер в `assets/` через ffmpeg (`ffmpeg -y -ss 3 -i video/имя.mp4 -frames:v 1 -vf scale=640:-2 assets/poster-имя.jpg`) и добавить кнопку `<button class="video-choice">` с `data-src`, `data-poster`, `data-title`. Пути к файлам с русскими буквами и пробелами писать в percent-кодировке. Ниже плеера стоит блок «Подарок от разработчика»: кнопка «Открыть своё видео» позволяет посмотреть свой файл во встроенном плеере; после выбора страница прокручивается к нему.
