- Кнопки съёмки кадров: `captureFramesBtn` «Снять 5 кадров» берёт пять моментов равномерно по всему ролику `(i+1)/6`, `captureFromCursorBtn` «Снять 20 кадров с этого места» — двадцать кадров подряд с шагом 0,1 с от текущей позиции курсора (`video.currentTime`), то есть окно 1,9 с; если до конца ролика меньше 1,9 с, старт сдвигается назад, чтобы кадров всё равно было двадцать. Третья кнопка `captureStepFramesBtn` «Снять 10 кадров подряд» снимает десять кадров с шагом в один кадр ролика — видно каждый кадр файла без пропусков, так сравнивают качество соседних кадров. Частота кадров заранее неизвестна, поэтому шаг подбирается на ходу: старт 0,012 с, при повторе кадра шаг растёт ×1,4 (до 8 попыток, кэп 0,1 с), при перескоке через кадр (`delta > frameStep × 1,5`) уменьшается вдвое; после удачного кадра шаг уточняется по `mediaTime` реально показанного кадра. Дубли определяются по `mediaTime` (`delta < 0,002`), а картинка — запасной путь, когда `mediaTime` нет. Общая функция `captureSeries(times, options)` при `options.stepFrames` работает в режиме шага по кадрам, иначе берёт готовый список `times`; перематывает видео, рисует каждый кадр в `<canvas>` в родном разрешении ролика и кладёт JPEG-ссылки в `#frameResults`; браузер на 4K иногда показывает один и тот же кадр для двух соседних моментов, поэтому после перемотки кадр сверяется с предыдущим по маленькому «отпечатку» (`frameSignature`, 32×18) и при совпадении перемотка повторяется от времени реально показанного кадра (`seekTo` возвращает `mediaTime` из `requestVideoFrameCallback`) со сдвигом +0,045 с (до трёх попыток; если несколько кадров подряд не меняются, сцена считается статичной и попытки прекращаются); перед началом серии ждём завершения чужой перемотки и 120 мс, иначе первый кадр может сняться не там; клик по миниатюре скачивает `кадр-N.jpg`. Прогресс идёт в `#frameStatus`, при смене ролика `clearFrames()` отзывает старые blob-ссылки и прячет архив. ID `captureFramesBtn`, `captureFromCursorBtn`, `captureStepFramesBtn`, `frameStatus`, `frameResults`, `downloadAllFramesBtn` сохранять. После съёмки появляется `downloadAllFramesBtn` «Скачать все кадры (ZIP)»: ZIP собирается вручную на чистом JS (метод store, CRC32, UTF-8-имена, без библиотек) и скачивается как `кадры.zip`. Надёжнее всего съёмка работает с роликом, выбранным через `videoFileInput` (blob:): при открытии сайта прямо с диска кадры роликов с сайта могут упереться в ограничение браузера — тогда подсказка просит открыть ролик кнопкой. Это не «скриншот экрана», а снимки кадров самого видео; по-другому браузер не даёт.

## Запуск локального сервера
- `start_site.cmd` в папке проекта — ярлык запуска: проверяет порт 8000, сам открывает браузер и держит сервер в своём окне (`python -m http.server 8000 --bind 127.0.0.1`). На рабочем столе ярлык «Мой сайт».
- Один ярлык = одно окно = один сервер; окно закрывать нельзя, пока смотришь сайт. Остановка — `Ctrl+C` в этом окне.
- Файл батника держать ASCII-only: `cmd.exe` ломается на кириллице в командных файлах.
- Камера и покадровая съёмка работают только по `http://127.0.0.1:8000/`, не по `file://`.
